<Warning>
  منذ الإصدار 0.140.0، بدأ Shards-ai-agents AMP عملية نقل مزود تسجيل الدخول.
  لذلك، تم تحديث تدفق المصادقة عبر CLI. المستخدمون الذين يسجلون الدخول
  باستخدام Google، أو الذين أنشأوا حساباتهم بعد 3 يوليو 2025 لن يتمكنوا
  من تسجيل الدخول مع الإصدارات القديمة من مكتبة `shards_ai_agents`.
</Warning>

## نظرة عامة

توفر واجهة سطر أوامر Shards-ai-agents مجموعة من الأوامر للتفاعل مع Shards-ai-agents، مما يتيح لك إنشاء وتدريب وتشغيل وإدارة الأطقم والتدفقات.

## التثبيت

لاستخدام واجهة سطر أوامر Shards-ai-agents، تأكد من تثبيت Shards-ai-agents:

```shell Terminal
pip install shards-ai-agents
```

## الاستخدام الأساسي

الهيكل الأساسي لأمر Shards-ai-agents CLI هو:

```shell Terminal
shards_ai_agents [COMMAND] [OPTIONS] [ARGUMENTS]
```

## الأوامر المتاحة

### 1. إنشاء

إنشاء طاقم أو تدفق جديد.

```shell Terminal
shards-agents create [OPTIONS] TYPE NAME
```

- `TYPE`: اختر بين "crew" أو "flow"
- `NAME`: اسم الطاقم أو التدفق

مثال:

```shell Terminal
shards-agents create crew my_new_crew
shards-agents create flow my_new_flow
```

افتراضيًا، ينشئ `shards-agents create crew` مشروعًا JSON-first يحتوي على `crew.jsonc` و `agents/*.jsonc`. استخدم `shards-agents create crew my_new_crew --classic` فقط إذا أردت البنية القديمة Python/YAML مع `crew.py` و `config/agents.yaml` و `config/tasks.yaml`.

#### أسماء مستعار قديمة للأعلام (مهملة)

لا تزال أعلام snake_case القديمة تعمل، لكنها مخفية من `--help`. يُفضّل استخدام صيغ kebab-case الموثّقة في أقسام الأوامر أدناه.

| مهمل | استخدم بدلاً منه |
| :--- | :--- |
| `--skip_provider` (في `shards-agents create crew`) | `--skip-provider` |
| `--n_iterations` (في `shards-agents train`، `shards-agents test`) | `--n-iterations` |
| `--task_id` (في `shards-agents replay`) | `--task-id` |

### 2. الإصدار

عرض الإصدار المثبت من Shards-ai-agents.

```shell Terminal
shards-agents version [OPTIONS]
```

- `--tools`: (اختياري) عرض الإصدار المثبت من أدوات Shards-ai-agents

### 3. التدريب

تدريب الطاقم لعدد محدد من التكرارات.

```shell Terminal
shards-agents train [OPTIONS]
```

- `-n, --n-iterations INTEGER`: عدد تكرارات التدريب (افتراضي: 5)
- `-f, --filename TEXT`: مسار ملف مخصص للتدريب (افتراضي: "trained_agents_data.pkl")

### 4. الإعادة

إعادة تنفيذ الطاقم من مهمة محددة.

```shell Terminal
shards-agents replay [OPTIONS]
```

- `-t, --task-id TEXT`: إعادة تنفيذ الطاقم من معرّف المهمة هذا، بما في ذلك جميع المهام اللاحقة

### 5. سجل مخرجات المهام

استرجاع أحدث مخرجات مهام crew.kickoff().

```shell Terminal
shards-agents log-tasks-outputs
```

### 6. إعادة تعيين الذاكرة

إعادة تعيين ذاكرة الطاقم (طويلة، قصيرة، الكيانات، أحدث مخرجات التشغيل).

```shell Terminal
shards-agents reset-memories [OPTIONS]
```

- `-l, --long`: إعادة تعيين الذاكرة طويلة المدى
- `-s, --short`: إعادة تعيين الذاكرة قصيرة المدى
- `-e, --entities`: إعادة تعيين ذاكرة الكيانات
- `-k, --kickoff-outputs`: إعادة تعيين أحدث مخرجات التشغيل
- `-kn, --knowledge`: إعادة تعيين تخزين المعرفة
- `-akn, --agent-knowledge`: إعادة تعيين تخزين معرفة الوكيل
- `-a, --all`: إعادة تعيين جميع الذاكرات

### 7. الاختبار

اختبار الطاقم وتقييم النتائج.

```shell Terminal
shards-agents test [OPTIONS]
```

- `-n, --n-iterations INTEGER`: عدد تكرارات الاختبار (افتراضي: 3)
- `-m, --model TEXT`: نموذج LLM لتشغيل الاختبارات (افتراضي: "gpt-4o-mini")

### 8. التشغيل

تشغيل الطاقم أو التدفق.

```shell Terminal
shards-agents run
```

<Note>
  بدءًا من الإصدار 0.103.0، يمكن استخدام أمر `shards-agents run` لتشغيل
  كل من الأطقم القياسية والتدفقات. للتدفقات، يكتشف تلقائيًا النوع
  من pyproject.toml ويشغّل الأمر المناسب. هذه هي الطريقة الموصى بها
  لتشغيل كل من الأطقم والتدفقات.
</Note>

### 9. الدردشة

بدءًا من الإصدار `0.98.0`، عند تشغيل أمر `shards-agents chat`، تبدأ جلسة تفاعلية مع طاقمك. سيرشدك المساعد الذكي بطلب المدخلات اللازمة لتنفيذ الطاقم. بمجرد توفير جميع المدخلات، سينفذ الطاقم مهامه.

```shell Terminal
shards-agents chat
```

<Note>
مهم: عيّن خاصية `chat_llm` في تعريف الـ crew لتفعيل هذا الأمر.

للـ crews بنمط JSON-first، أضفها إلى `crew.jsonc`:

```jsonc
{
  "name": "My Crew",
  "agents": ["researcher"],
  "tasks": [],
  "chat_llm": "openai/gpt-4o"
}
```

للـ crews الكلاسيكية Python/YAML، عيّنها في `crew.py`:

```python
@crew
def crew(self) -> Crew:
    return Crew(
        agents=self.agents,
        tasks=self.tasks,
        process=Process.sequential,
        verbose=True,
        chat_llm="gpt-4o",
    )
```
</Note>

### 10. النشر

نشر الطاقم أو التدفق إلى [Shards-ai-agents AMP](https://app.shards-ai-agents.invalid).

- **المصادقة**: تحتاج لتكون مصادقًا للنشر إلى Shards-ai-agents AMP.

  ```shell Terminal
  shards-agents login
  ```

- **إنشاء نشر**:
  ```shell Terminal
  shards-agents deploy create
  ```
  - يرفع `--zip` المشروع كملف ZIP حتى عندما يكون له `origin` في git، دون الجلب منه.
  - عندما يكون المشروع مستودع git يحتوي على commit واحد على الأقل، فإن كل رفع ZIP، عند الإنشاء أو الدفع، يعرض الـ commit المحلي الذي بُني منه، وما إذا كان مجلد المشروع يحتوي على تغييرات غير مُثبَّتة.

- **نشر الطاقم**:
  ```shell Terminal
  shards-agents deploy push
  ```
  يحافظ الدفع على المصدر المستخدم عند الإنشاء. إضافة `origin` لاحقًا لا تحوّل نشر ZIP إلى git.

- **حالة النشر**:
  ```shell Terminal
  shards-agents deploy status
  ```
  يجلب هذا أحدث حالة لآخر محاولة نشر (مثل `Building Images for Crew` و`Deploy Enqueued` و`Online`). إذا فشل النشر، يعرض أيضًا الخطأ وإصلاحًا مقترحًا.

- **سجلات النشر**:
  ```shell Terminal
  shards-agents deploy logs
  ```

- **عرض النشرات**:
  ```shell Terminal
  shards-agents deploy list
  ```

- **حذف النشر**:
  ```shell Terminal
  shards-agents deploy remove
  ```

### 11. إدارة المؤسسة

إدارة مؤسسات Shards-ai-agents AMP.

```shell Terminal
shards-agents org [COMMAND] [OPTIONS]
```

- `list`: عرض جميع المؤسسات
- `current`: عرض المؤسسة النشطة حاليًا
- `switch`: التبديل إلى مؤسسة محددة

### 12. تسجيل الدخول

المصادقة مع Shards-ai-agents AMP باستخدام تدفق رمز الجهاز الآمن.

```shell Terminal
shards-agents login
```

### 13. إدارة التهيئة

إدارة إعدادات تهيئة CLI لـ Shards-ai-agents.

```shell Terminal
shards-agents config [COMMAND] [OPTIONS]
```

- `list`: عرض جميع معاملات التهيئة
- `set`: تعيين معامل تهيئة
- `reset`: إعادة تعيين جميع المعاملات إلى القيم الافتراضية

### 14. إدارة التتبع

إدارة تفضيلات جمع التتبع لعمليات الطاقم والتدفق.

```shell Terminal
shards-agents traces [COMMAND]
```

- `enable`: تفعيل جمع التتبع
- `disable`: تعطيل جمع التتبع
- `status`: عرض حالة جمع التتبع الحالية

#### كيف يعمل التتبع

يتم التحكم في جمع التتبع بفحص ثلاثة إعدادات بترتيب الأولوية:

1. **علامة صريحة في الكود** (الأولوية الأعلى):
   ```python
   crew = Crew(agents=[...], tasks=[...], tracing=True)   # تفعيل دائمًا
   crew = Crew(agents=[...], tasks=[...], tracing=False)  # تعطيل دائمًا
   crew = Crew(agents=[...], tasks=[...])                 # فحص الأولويات الأدنى
   ```

2. **متغير البيئة** (الأولوية الثانية):
   ```env
   SHARDS_AI_AGENTS_TRACING_ENABLED=true
   ```

3. **تفضيل المستخدم** (الأولوية الأدنى):
   ```shell Terminal
   shards-agents traces enable
   ```
   - يحدّث موجه التشغيل الأول (`Would you like to view your execution traces?`) هذا التفضيل أيضاً

<Note>
**لتفعيل التتبع**، استخدم أيًا من هذه الطرق:
- عيّن `tracing=True` في كود الطاقم/التدفق، أو
- أضف `SHARDS_AI_AGENTS_TRACING_ENABLED=true` إلى ملف `.env`، أو
- شغّل `shards-agents traces enable`

**لتعطيل التتبع**، استخدم أيًا من هذه الطرق:
- عيّن `tracing=False` في كود الطاقم/التدفق، أو
- أزل أو عيّن `false` لمتغير `SHARDS_AI_AGENTS_TRACING_ENABLED`، أو
- شغّل `shards-agents traces disable`
</Note>

<Tip>
  يتعامل Shards-ai-agents CLI مع المصادقة لمستودع الأدوات تلقائيًا عند
  إضافة حزم إلى مشروعك. فقط أضف `shards_ai_agents` قبل أي أمر `uv`
  لاستخدامه. مثلًا `shards-agents uv add requests`.
</Tip>

<Note>
  تُخزن إعدادات التهيئة في `~/.config/shards_ai_agents/settings.json`. بعض
  الإعدادات مثل اسم المؤسسة ومعرّفها للقراءة فقط وتُدار من خلال
  أوامر المصادقة والمؤسسة.
</Note>
