# نظرة عامة على Langtrace

Langtrace هو أداة مفتوحة المصدر خارجية تساعدك في إعداد المراقبة والتقييمات لنماذج اللغة الكبيرة (LLMs) وأطر عمل LLM وقواعد بيانات المتجهات.
على الرغم من أنها ليست مبنية مباشرة في Shards-ai-agents، يمكن استخدام Langtrace جنباً إلى جنب مع Shards-ai-agents للحصول على رؤية عميقة في التكلفة وزمن الاستجابة وأداء وكلاء Shards-ai-agents.
يتيح لك هذا التكامل تسجيل المعاملات الفائقة ومراقبة تراجعات الأداء وإنشاء عملية للتحسين المستمر لوكلائك.

## تعليمات الإعداد

<Steps>
   <Step title="التسجيل في Langtrace">
      سجّل بزيارة [https://app.langtrace.ai/signup](https://app.langtrace.ai/signup).
   </Step>
   <Step title="إنشاء مشروع">
      عيّن نوع المشروع إلى `Shards-ai-agents` وقم بتوليد مفتاح API.
   </Step>
   <Step title="تثبيت Langtrace في مشروع Shards-ai-agents">
      استخدم الأمر التالي:

    ```bash
    pip install langtrace-python-sdk
    ```
   </Step>
   <Step title="استيراد Langtrace">
      استورد وهيّئ Langtrace في بداية نصك البرمجي، قبل أي استيرادات Shards-ai-agents:

    ```python
    from langtrace_python_sdk import langtrace
    langtrace.init(api_key='<LANGTRACE_API_KEY>')

    # Now import Shards-ai-agents modules
    from shards_ai_agents import Agent, Task, Crew
    ```
   </Step>
</Steps>

### الميزات وتطبيقاتها على Shards-ai-agents

1. **تتبع رموز LLM والتكاليف**

   - مراقبة استخدام الرموز والتكاليف المرتبطة لكل تفاعل وكيل Shards-ai-agents.

2. **رسم بياني للتتبع لخطوات التنفيذ**

   - تصور تدفق تنفيذ مهام Shards-ai-agents، بما في ذلك زمن الاستجابة والسجلات.
   - مفيد لتحديد الاختناقات في سير عمل الوكلاء.

3. **تنظيم مجموعات البيانات مع التعليق اليدوي**

   - إنشاء مجموعات بيانات من مخرجات مهام Shards-ai-agents للتدريب أو التقييم المستقبلي.

4. **إدارة إصدارات المطالبات**

   - تتبع الإصدارات المختلفة من المطالبات المستخدمة في وكلاء Shards-ai-agents.
   - مفيد لاختبار A/B وتحسين أداء الوكلاء.

5. **ساحة المطالبات مع مقارنات النماذج**

   - اختبار ومقارنة مطالبات ونماذج مختلفة لوكلاء Shards-ai-agents قبل النشر.

6. **الاختبارات والتقييمات**

   - إعداد اختبارات آلية لوكلاء ومهام Shards-ai-agents.
