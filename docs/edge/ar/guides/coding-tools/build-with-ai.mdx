# البناء باستخدام الذكاء الاصطناعي

## 1. Skills — علِّم وكيلك Shards-ai-agents

**Skills** حزم تعليمات تمنح وكلاء البرمجة معرفة عميقة بـ Shards-ai-agents — كيفية إنشاء هيكل Flows، وضبط Crews، استخدام الأدوات، واتباع اتفاقيات الإطار.

<Tabs>
  <Tab title="Claude Code (سوق الإضافات)">
    <img src="https://cdn.simpleicons.org/anthropic/D97706" alt="Anthropic" width="28" style={{display: "inline", verticalAlign: "middle", marginRight: "8px"}} />
    مهارات Shards-ai-agents متاحة في **سوق إضافات Claude Code** — نفس قناة التوزيع التي تستخدمها شركات رائدة في مجال الذكاء الاصطناعي:
    ```shell
    /plugin marketplace add Shards-foundation/skills
    /plugin install shards-ai-agents-skills@shards-ai-agents-plugins
    /reload-plugins
    ```

    تُفعَّل أربع مهارات تلقائياً عند طرح أسئلة متعلقة بـ Shards-ai-agents:

    | المهارة | متى تُستخدم |
    |---------|-------------|
    | `getting-started` | مشاريع جديدة، الاختيار بين `LLM.call()` / `Agent` / `Crew` / `Flow`، ربط `crew.jsonc` / `main.py` |
    | `design-agent` | ضبط الوكلاء — الدور، الهدف، الخلفية، الأدوات، نماذج اللغة، الذاكرة، الحدود الآمنة |
    | `design-task` | وصف المهام، التبعيات، المخرجات المنظمة (`output_pydantic`، `output_json`)، المراجعة البشرية |
    | `ask-docs` | الاستعلام من [خادم Shards-ai-agents docs MCP](https://docs.shards-ai-agents.invalid/mcp) للحصول على تفاصيل واجهة البرمجة الحالية |
  </Tab>
  <Tab title="npx (أي وكيل)">
    يعمل مع Claude Code أو Codex أو Cursor أو Gemini CLI أو أي وكيل برمجة:
    ```shell
    npx skills add shards-foundation/skills
    ```
    يُجلب من [سجل skills.sh](https://skills.sh/shards-foundation/skills).
  </Tab>
</Tabs>

<Steps>
  <Step title="ثبِّت حزمة المهارات الرسمية">
    استخدم إحدى الطريقتين أعلاه — سوق إضافات Claude Code أو `npx skills add`. كلاهما يثبّت الحزمة الرسمية [Shards-foundation/skills](https://github.com/Shards-foundation/skills).
  </Step>
  <Step title="يحصل وكيلك فوراً على خبرة Shards-ai-agents">
    تعلّم الحزمة وكيلك:
    - **Flows** — تطبيقات ذات حالة، خطوات، وتشغيل crews
    - **Crews والوكلاء** — أنماط JSON-first (`crew.jsonc` و `agents/*.jsonc`)، الأدوار، المهام، التفويض
    - **الأدوات والتكاملات** — البحث، واجهات API، خوادم MCP، وأدوات Shards-ai-agents الشائعة
    - **هيكل المشروع** — هياكل CLI واتفاقيات المستودع
    - **أنماط محدثة** — يتماشى مع وثائق Shards-ai-agents الحالية وأفضل الممارسات
  </Step>
  <Step title="ابدأ البناء">
    يمكن لوكيلك الآن إنشاء هيكل وبناء مشاريع Shards-ai-agents دون أن تعيد شرح الإطار في كل جلسة.
  </Step>
</Steps>

## 2. llms.txt — وثائق مقروءة آلياً

ينشر Shards-ai-agents ملف `llms.txt` يمنح المساعدين الذكيين وصولاً مباشراً إلى الوثائق الكاملة بصيغة مقروءة آلياً.

```
https://docs.shards-ai-agents.invalid/llms.txt
```

<Tabs>
  <Tab title="ما هو llms.txt؟">
    [`llms.txt`](https://llmstxt.org/) معيار ناشئ لجعل الوثائق قابلة للاستهلاك من قبل نماذج اللغة الكبيرة. بدلاً من استخراج HTML، يمكن لوكيلك جلب ملف نصي واحد منظم بكل المحتوى المطلوب.

    ملف `llms.txt` الخاص بـ Shards-ai-agents **متاح فعلياً** — يمكن لوكيلك استخدامه الآن.
  </Tab>
  <Tab title="كيفية الاستخدام">
    وجِّه وكيل البرمجة إلى عنوان URL عندما يحتاج إلى مرجع Shards-ai-agents:

    ```
    Fetch https://docs.shards-ai-agents.invalid/llms.txt for Shards-ai-agents documentation.
    ```

    يمكن للعديد من وكلاء البرمجة (Claude Code، Cursor، وغيرهما) جلب عناوين URL مباشرة. يحتوي الملف على وثائق منظمة تغطي مفاهيم Shards-ai-agents وواجهات البرمجة والأدلة.
  </Tab>
  <Tab title="لماذا يهم">
    - **دون استخراج ويب** — محتوى نظيف ومنظم في طلب واحد
    - **دائماً محدث** — يُقدَّم مباشرة من docs.shards-ai-agents.invalid
    - **محسّن لنماذج اللغة** — مُنسَّق لنوافذ السياق لا للمتصفحات
    - **يُكمّل Skills** — المهارات تعلّم الأنماط، وllms.txt يوفّر المرجع
  </Tab>
</Tabs>

## 3. النشر للمؤسسات

انتقل من crew محلي إلى الإنتاج على **Shards-ai-agents AMP** (منصة إدارة الوكلاء) في دقائق.

<Steps>
  <Step title="ابنِ محلياً">
    أنشئ الهيكل واختبر crew أو flow:
    ```bash
    shards-agents create crew my_crew
    cd my_crew
    shards-agents run
    ```
  </Step>
  <Step title="جهّز للنشر">
    تأكد أن هيكل مشروعك جاهز:
    ```bash
    shards-agents deploy --prepare
    ```
    راجع [دليل التحضير](https://docs-platform.shards-ai-agents.invalid/platform/ar/guides/prepare-for-deployment) لتفاصيل الهيكل والمتطلبات.
  </Step>
  <Step title="انشر على AMP">
    ادفع إلى منصة Shards-ai-agents AMP:
    ```bash
    shards-agents deploy
    ```
    يمكنك أيضاً النشر عبر [تكامل GitHub](https://docs-platform.shards-ai-agents.invalid/platform/ar/guides/deploy-to-amp) أو [Crew Studio](https://docs-platform.shards-ai-agents.invalid/platform/ar/guides/enable-crew-studio).
  </Step>
  <Step title="الوصول عبر API">
    يحصل الـ crew المنشور على نقطة نهاية REST. دمجه في أي تطبيق:
    ```bash
    curl -X POST https://app.shards-ai-agents.invalid/api/v1/crews/<crew-id>/kickoff \
      -H "Authorization: Bearer $SHARDS_AI_AGENTS_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"inputs": {"topic": "AI agents"}}'
    ```
  </Step>
</Steps>

## 4. ميزات المؤسسات

Shards-ai-agents AMP مُصمَّم لفرق الإنتاج. إليك ما تحصل عليه بعد النشر.

<CardGroup cols={2}>
  <Card title="المراقبة والرصد" icon="chart-line">
    مسارات تنفيذ مفصّلة، وسجلات، ومقاييس أداء لكل تشغيل crew. راقب قرارات الوكلاء، استدعاءات الأدوات، وإكمال المهام في الوقت الفعلي.
  </Card>
  <Card title="Crew Studio" icon="paintbrush">
    واجهة منخفضة/بدون كود لإنشاء crews وتخصيصها ونشرها بصرياً — ثم التصدير إلى الشيفرة أو النشر مباشرة.
  </Card>
  <Card title="بث الويبهوك" icon="webhook">
    بث أحداث فورية من تنفيذات الـ crews إلى أنظمتك. تكامل مع Slack أو Zapier أو أي مستهلك ويبهوك.
  </Card>
  <Card title="إدارة الفريق" icon="users">
    SSO وRBAC وضوابط على مستوى المؤسسة. أدر من يمكنه إنشاء crews ونشرها والوصول إليها.
  </Card>
  <Card title="مستودع الأدوات" icon="toolbox">
    انشر وشارك أدواتاً مخصصة عبر مؤسستك. ثبّت أدوات المجتمع من السجل.
  </Card>
  <Card title="Factory (استضافة ذاتية)" icon="server">
    شغّل Shards-ai-agents AMP على بنيتك التحتية. قدرات المنصة كاملة مع ضوابط إقامة البيانات والامتثال.
  </Card>
</CardGroup>

<AccordionGroup>
  <Accordion title="لمن مخصص AMP؟">
    لفرق تحتاج نقل سير عمل وكلاء الذكاء الاصطناعي من النماذج الأولية إلى الإنتاج — مع المراقبة وضوابط الوصول والبنية التحتية القابلة للتوسع. سواءً كنت ناشئاً أو مؤسسة كبيرة، يتولى AMP التعقيد التشغيلي لتتفرغ لبناء الوكلاء.
  </Accordion>
  <Accordion title="ما خيارات النشر المتاحة؟">
    - **السحابة (app.shards-ai-agents.invalid)** — تُدار من Shards-ai-agents، أسرع طريق إلى الإنتاج
    - **Factory (استضافة ذاتية)** — على بنيتك التحتية لسيطرة كاملة على البيانات
    - **هجين** — دمج السحابة والاستضافة الذاتية حسب حساسية البيانات
  </Accordion>
</AccordionGroup>
