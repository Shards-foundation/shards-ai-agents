# Skills

**امنح وكيل البرمجة سياق Shards-ai-agents في أمر واحد.**

تُنشر **Skills** الخاصة بـ Shards-ai-agents على **[skills.sh/shards-foundation/skills](https://skills.sh/shards-foundation/skills)**—السجل الرسمي لـ `shards-foundation/skills`، بما في ذلك كل مهارة (مثل **design-agent** و**getting-started** و**design-task** و**ask-docs**) وإحصاءات التثبيت والتدقيقات. تعلّم وكلاء البرمجة—مثل Claude Code وCursor وCodex—هيكلة Flows وضبط Crews واستخدام الأدوات واتباع أنماط Shards-ai-agents. نفّذ الأمر أدناه (أو الصقه في الوكيل).

```shell Terminal
npx skills add shards-foundation/skills
```

يضيف ذلك حزمة المهارات إلى سير عمل الوكيل لتطبيق اتفاقيات Shards-ai-agents دون إعادة شرح الإطار في كل جلسة. المصدر والقضايا على [GitHub](https://github.com/Shards-foundation/skills).

## ما يحصل عليه الوكيل

- **Flows** — تطبيقات ذات حالة وخطوات وkickoffs للـ crew على نمط Shards-ai-agents
- **Crews والوكلاء** — أنماط JSON-first (`crew.jsonc` و `agents/*.jsonc`)، أدوار، مهام، وتفويض
- **الأدوات والتكاملات** — ربط الوكلاء بالبحث وواجهات API وأدوات Shards-ai-agents الشائعة
- **هيكل المشروع** — مواءمة مع قوالب CLI واتفاقيات المستودع
- **أنماط محدثة** — تتبع المهارات وثائق Shards-ai-agents والممارسات الموصى بها
