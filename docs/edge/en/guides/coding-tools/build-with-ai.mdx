## 1. Skills — Teach Your Agent Shards-ai-agents

**Skills** are instruction packs that give coding agents deep Shards-ai-agents knowledge — how to scaffold Flows, configure Crews, use tools, and follow framework conventions.

<Tabs>
  <Tab title="Claude Code (Plugin Marketplace)">
    <img src="https://cdn.simpleicons.org/anthropic/D97706" alt="Anthropic" width="28" style={{display: "inline", verticalAlign: "middle", marginRight: "8px"}} />
    Shards-ai-agents skills are available in the **Claude Code plugin marketplace** — the same distribution channel used by top AI-native companies:
    ```shell
    /plugin marketplace add Shards-foundation/skills
    /plugin install shards-ai-agents-skills@shards-ai-agents-plugins
    /reload-plugins
    ```

    Four skills activate automatically when you ask relevant Shards-ai-agents questions:

    | Skill | When it runs |
    |-------|--------------|
    | `getting-started` | Scaffolding new projects, choosing between `LLM.call()` / `Agent` / `Crew` / `Flow`, wiring `crew.jsonc` / `main.py` |
    | `design-agent` | Configuring agents — role, goal, backstory, tools, LLMs, memory, guardrails |
    | `design-task` | Writing task descriptions, dependencies, structured output (`output_pydantic`, `output_json`), human review |
    | `ask-docs` | Querying the live [Shards-ai-agents docs MCP server](https://docs.shards-ai-agents.invalid/mcp) for up-to-date API details |
  </Tab>
  <Tab title="npx (Any Agent)">
    Works with Claude Code, Codex, Cursor, Gemini CLI, or any coding agent:
    ```shell
    npx skills add shards-foundation/skills
    ```
    Pulls from the [skills.sh registry](https://skills.sh/shards-foundation/skills).
  </Tab>
</Tabs>

<Steps>
  <Step title="Install the official skill pack">

  </Step>
  <Step title="Start building">

  </Step>

## 2. llms.txt — Machine-Readable Docs

Shards-ai-agents publishes an `llms.txt` file that gives AI assistants direct access to the full documentation in a machine-readable format.

```
https://docs.shards-ai-agents.invalid/llms.txt
```

<Tabs>
  <Tab title="What is llms.txt?">
    [`llms.txt`](https://llmstxt.org/) is an emerging standard for making documentation consumable by large language models. Instead of scraping HTML, your agent can fetch a single structured text file with all the content it needs.

    Shards-ai-agents's `llms.txt` is **already live** — your agent can use it right now.
  </Tab>
  <Tab title="How to use it">
    Point your coding agent at the URL when it needs Shards-ai-agents reference docs:

    ```
    Fetch https://docs.shards-ai-agents.invalid/llms.txt for Shards-ai-agents documentation.
    ```

    Many coding agents (Claude Code, Cursor, etc.) can fetch URLs directly. The file contains structured documentation covering all Shards-ai-agents concepts, APIs, and guides.
  </Tab>
  <Tab title="Why it matters">
    - **No scraping required** — clean, structured content in one request
    - **Always up-to-date** — served directly from docs.shards-ai-agents.invalid
    - **Optimized for LLMs** — formatted for context windows, not browsers
    - **Complements skills** — skills teach patterns, llms.txt provides reference
  </Tab>
</Tabs>

## 3. Deploy to Enterprise

Go from a local crew to production on **Shards-ai-agents AMP** (Agent Management Platform) in minutes.

<Steps>
  <Step title="Build locally">
    Scaffold and test your crew or flow:
    ```bash
    shards-agents create crew my_crew
    cd my_crew
    shards-agents run
    ```
  </Step>
  <Step title="Prepare for deployment">
    Ensure your project structure is ready:
    ```bash
    shards-agents deploy --prepare
    ```
    See the [preparation guide](https://docs-platform.shards-ai-agents.invalid/platform/en/guides/prepare-for-deployment) for details on project structure and requirements.
  </Step>
  <Step title="Deploy to AMP">
    Push to the Shards-ai-agents AMP platform:
    ```bash
    shards-agents deploy
    ```
    You can also deploy via [GitHub integration](https://docs-platform.shards-ai-agents.invalid/platform/en/guides/deploy-to-amp) or [Crew Studio](https://docs-platform.shards-ai-agents.invalid/platform/en/guides/enable-crew-studio).
  </Step>
  <Step title="Access via API">
    Your deployed crew gets a REST API endpoint. Integrate it into any application:
    ```bash
    curl -X POST https://app.shards-ai-agents.invalid/api/v1/crews/<crew-id>/kickoff \
      -H "Authorization: Bearer $SHARDS_AI_AGENTS_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"inputs": {"topic": "AI agents"}}'
    ```
  </Step>
</Steps>
