# Skills

**Give your AI coding agent Shards-ai-agents context in one command.**

Shards-ai-agents **Skills** are published on **[skills.sh/shards-foundation/skills](https://skills.sh/shards-foundation/skills)**—the official registry for `shards-foundation/skills`, including individual skills (for example **design-agent**, **getting-started**, **design-task**, and **ask-docs**), install stats, and audits. They teach coding agents—like Claude Code, Cursor, and Codex—how to scaffold Flows, configure Crews, use tools, and follow Shards-ai-agents patterns. Run the install below (or paste it into your agent).

```shell Terminal
npx skills add shards-foundation/skills
```

That pulls the official skill pack into your agent workflow so it can apply Shards-ai-agents conventions without you re-explaining the framework each session. Source code and issues live on [GitHub](https://github.com/Shards-foundation/skills).

## What your agent gets

- **Flows** — structure stateful apps, steps, and crew kickoffs the Shards-ai-agents way
- **Crews & agents** — JSON-first patterns (`crew.jsonc`, `agents/*.jsonc`), roles, tasks, and delegation
- **Tools & integrations** — hook agents to search, APIs, and common Shards-ai-agents tools
- **Project layout** — align with CLI scaffolds and repo conventions
- **Up-to-date patterns** — skills track current Shards-ai-agents docs and recommended practices
